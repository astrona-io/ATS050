# Exporters

The first module covers how exporters translate state into metrics, how to read scrape health and diagnose failures, and how multi-target exporters such as the Blackbox Exporter are configured. The second module covers the Node Exporter, the textfile collector, safe writing of metric files and the choice between an exporter, the textfile collector and the Pushgateway. Each module has a guided practice page, a graded lab and a summary. An exporters capstone lab and a knowledge check close the section.

Read the pages of each module in order. The landing page of each module states its goals, and the summary closes it. Knowledge checks are listed separately in the course manifest.

## Learning Outcomes

- Translate the state of an external system into metrics with correct names, units and labels.
- Separate scrape health from application health and diagnose a missing metric.
- Configure a multi-target exporter with relabeling and handle credentials safely.
- Publish machine-level metrics through the Node Exporter textfile collector.
