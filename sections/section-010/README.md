# Client Libraries

The first module covers what a client library does, how a registry holds metric families and label children, and how process lifecycle and concurrent collection affect correctness. The second module covers the four metric types, the structure of histograms and summaries, and the text exposition format. Each module has a guided practice page, a graded lab and a summary. A capstone lab repairs a broken endpoint, and a knowledge check closes the section.

Read the pages of each module in order. The landing page of each module states its goals, and the summary closes it. Knowledge checks are listed separately in the course manifest.

## Learning Outcomes

- Explain what a client library provides: metric types, a registry, an exposition handler and default collectors.
- Choose a counter, a gauge, a histogram or a summary from the meaning of the quantity.
- Bound label children and account for the lifecycle of a process.
- Read the text exposition format, including histogram buckets, and judge whether an endpoint is valid.
