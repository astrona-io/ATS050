# Structuring and naming metrics

The first module covers metric names, units and suffixes, label design and info metrics, and how to change a metric contract safely. The second module covers cardinality: how series multiply, how to find the metrics and labels that cost the most, and how to control them with source fixes, relabeling, scrape limits and recording rules. Each module has a guided practice page, a graded lab and a summary. A capstone lab and a knowledge check close the section.

Read the pages of each module in order. The landing page of each module states its goals, and the summary closes it. Knowledge checks are listed separately in the course manifest.

## Learning Outcomes

- Name metrics with base units and the correct suffix for their type.
- Decide between a label and a separate metric, and keep label values bounded.
- Change names and labels without silently breaking dashboards and alerts.
- Calculate, find and control cardinality at the source, at scrape time and with limits.
