# Summary

Useful instrumentation begins with an operational question and a defined population. Request counts, failure counts, duration distributions and saturation measurements describe complementary aspects of service behavior.

Measure consistent lifecycle boundaries, include relevant failure paths and normalize label dimensions. Retries, nested calls and asynchronous work can change denominators, while instrumentation overhead and confidentiality remain design considerations.
