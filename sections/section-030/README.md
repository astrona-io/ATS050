# Exporters

This section covers exporters. It develops exporters, Target Failure And Multi-Target Probes through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain translation from external system state to metrics.
- Distinguish exporter scrape health from backend health.
- Interpret multi-target exporter request and relabeling responsibilities.
- Control collection cost, credentials and partial failure evidence.
