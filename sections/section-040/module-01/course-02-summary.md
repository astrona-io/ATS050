# Summary

Metric names should identify a coherent quantity and unit, while labels supply useful bounded dimensions. Counter suffixes and base-unit naming help readers choose appropriate calculations.

Unbounded values and mixed semantics make series expensive or misleading. Instrumentation changes create compatibility work for queries, recordings and alerts, so rename or relabel deliberately and preserve a documented transition rather than silently reinterpret old data.
